# 你好，我是 Deming ZHOU 👋

我把北京地铁 19 号线的驾驶台搬进了浏览器，也给 macOS 上的 Codex 做了一个微信工具。

## 🚇 中国地铁列车驾驶模拟器

在模拟驾驶台上，可以一边操作列车，一边看速度随行驶距离怎样变化。换到调度中心工作站，就能从另一个视角看同一条线路。整个模拟器用静态网页实现。

[查看模拟器和运行方式 →](https://github.com/betaxiaozhou/metro-simulator-web)

## 💬 WeChat Message Sender for Codex

在 Mac 上，可以直接请 Codex 把一段文字或本地文件发给微信联系人。插件会先列出匹配的联系人，等你选定收件人，再通过已登录的微信桌面端发送。

[查看插件和安装说明 →](https://github.com/betaxiaozhou/wechat-message-sender)
